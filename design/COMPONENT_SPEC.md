# Σύνταξη «σημασιολογικού markdown» για τον μετατροπέα (pandoc fenced divs)

Τα drafts ξαναγράφονται σε `drafts2/` με την ίδια ουσία αλλά με συστατικά (components) αντί για πίνακες-layout. Χρησιμοποιούμε pandoc **fenced divs** `::: {.class attr="..."}` … `:::`. Μέσα σε div επιτρέπεται κανονικό markdown. Κενή γραμμή πριν και μετά από κάθε `:::`.

## Δομή σελίδας / κεφαλαίου
- `# Μέρος N – Τίτλος` → νέο κεφάλαιο, ξεκινά σε νέα σελίδα (ο μετατροπέας το κάνει).
- `## ` ενότητα, `### ` υποενότητα. Ποτέ `####`.
- Υποχρεωτικό attribute στο `#` των μαθημάτων: `# Μάθημα 2.1 – Φανάρι {.lesson level="2" id="l-2-1"}`
- Επίπεδο (εισαγωγή επιπέδου): `# Επίπεδο 2 – Ένας αισθητήρας, μία έξοδος {.level-intro level="2"}`
- Εξαναγκασμένη αλλαγή σελίδας: μια γραμμή `::: {.page-break}` `:::` (κενό div). Κάθε εκτυπώσιμο του Παραρτήματος Γ ξεκινά με `## Γx – Τίτλος {.printable}` → νέα σελίδα αυτόματα.

## Κάρτα «με μια ματιά» (μία ανά μάθημα, αμέσως μετά τον τίτλο)
```
::: {.glance level="2" dd="2" dm="2" time="40" grades="Γ'–ΣΤ'" concept="ακολουθία, για πάντα, παύση"}
**Θα φτιάξουμε** ένα φανάρι κυκλοφορίας με κόκκινο, κίτρινο και πράσινο LED που ανάβουν με τη σειρά.

ΔΔ: Μόνο PlanetX, χωρίς αισθητήρα· ό,τι μπορεί να πάει στραβά είναι θύρα ή καλώδιο.
ΔΜ: Τρία μπλοκ που επαναλαμβάνονται· η πρώτη επαφή με το «για πάντα».
Προαπαιτούμενα: 1.1
:::
```
(Οι γραμμές «ΔΔ:», «ΔΜ:», «Προαπαιτούμενα:» είναι υποχρεωτικές με αυτή ακριβώς τη μορφή.)

## Υλικά και θύρες
```
::: {.materials}
- LED κόκκινο → `J1`
- LED κίτρινο → `J2`
- 3 καλώδια RJ11
- micro:bit στην πλακέτα Nezha
- τουβλάκια για τον «στύλο»
- Εκτός kit: γλάστρα με χώμα, ποτήρι νερό
:::
```
Ο μετατροπέας βάζει εικονίδιο ανάλογα με τη λέξη-κλειδί (LED, καλώδ, micro:bit, κινητήρ, servo, αισθητήρ, τουβλ, εκτός kit) και κάνει chip ό,τι είναι σε backticks με μορφή J1/M1/S1.

## Ροή μαθήματος (χρονογραμμή)
```
::: {.timeline}
- **0–5'** Συζήτηση: πόσο διαρκεί το κόκκινο στο φανάρι έξω από το σχολείο;
- **5–15'** Κατασκευή και σύνδεση στις `J1` `J2` `J3`.
- **15–28'** Προγραμματισμός.
:::
```

## Κώδικας
```
::: {.code-figure id="fig-2-1" src="img/code-2-1.png" caption="Ο κώδικας του Φαναριού" link="https://makecode.microbit.org/_xxxx"}
:::

::: {.steps}
1. `LED J1 toggle to ON` ανάβει το κόκκινο.
2. `παύση (5000 ms)` περιμένει 5 δευτερόλεπτα.
:::
```
Αν δεν υπάρχει ακόμα εικόνα, ο μετατροπέας δείχνει placeholder 16:9 (max 100 mm) με τη λεζάντα. Η εικόνα πιάνει όλο το πλάτος· το `link` εμφανίζεται από κάτω ως `.linkbox`: «Άνοιξε τον κώδικα», το URL σε mono και QR 16 mm δεξιά.

## Τι θα πάει στραβά (κάρτες, ΟΧΙ πίνακας)
```
::: {.trouble}
- **Δεν ανάβει κανένα LED** — Γιατί: δεν προστέθηκε το PlanetX ή η πλακέτα είναι κλειστή. Κάνε: δες αν υπάρχει η κατηγορία PlanetX αριστερά· άνοιξε την πλακέτα με το κουμπί λειτουργίας.
- **Ανάβουν δύο LED μαζί** — Γιατί: … Κάνε: …
:::
```
Μορφή κάθε γραμμής: `- **Σύμπτωμα** — Γιατί: … Κάνε: …` (οι λέξεις «Γιατί:» και «Κάνε:» υποχρεωτικές).

## Πλαίσια (callouts) και πλαϊνές σημειώσεις
```
::: {.tip}        Συμβουλή
::: {.warn}       Προσοχή
::: {.safety}     Ασφάλεια
::: {.note}       Σημείωση δασκάλου
::: {.aside}      πλαίσιο «ΣΗΜΕΙΩΣΗ» μέσα στη ροή (≤40 λέξεις): παρατήρηση, όχι οδηγία
::: {.humor}      πλαίσιο «ΓΙΑ ΓΕΛΙΑ» μέσα στη ροή (≤30 λέξεις), ένα ανά μάθημα
::: {.humor v="2"}  εκδοχή εικονιδίου: 1 (πρόσωπο, προεπιλογή), 2 (κλόουν + καπέλο), 3 (φούσκα «ha!»)
```
Προαιρετικός τίτλος: `::: {.tip title="Βαθμονόμηση"}`. Οδηγίες («κάνε/μην κάνεις/πρόσεξε») γράφονται ως `.tip` ή `.warn`, όχι ως `.aside`/`.humor`.

## Κάρτα Πρόκλησης
Μπαίνει στη ροή, σε όλο το πλάτος, με διακεκομμένο περίγραμμα.
```
::: {.challenge}
Προσθέστε κουμπί πεζού: όταν πατηθεί το Α, το φανάρι γίνεται κόκκινο σε 5 δευτερόλεπτα.
:::
```

## Διαφοροποίηση (δύο στήλες-κάρτες)
```
::: {.diff}
- **Γ'–Δ'** Έτοιμος κώδικας από το link· αλλάζουν μόνο τους χρόνους.
- **Ε'–ΣΤ'** Χτίζουν τον κώδικα από το μηδέν· προσθέτουν τον πεζό.
:::
```

## Κάρτες ρόλων / εκτυπώσιμα
```
::: {.cards cols="3"}
::: {.card title="Κατασκευαστής"}
- Χτίζει με τα τουβλάκια…
:::
::: {.card title="Προγραμματιστής"}
…
:::
:::
```
Checklists: κανονική λίστα markdown με `- [ ] ` (ο μετατροπέας βάζει κουτάκια). Πεδία συμπλήρωσης: `Ομάδα εργασίας: ______`.

## Πίνακες
Επιτρέπονται ΜΟΝΟ: συγκεντρωτικός πίνακας μαθημάτων (`{.table-lessons}` → landscape σελίδα), πίνακας θυρών/συνδέσεων (≤3 στήλες, σύντομα κελιά), λεξικό (2–3 στήλες, ≤4 λέξεις ανά κελί, `{.table-glossary}`), ωράριο 90'/60' (`{.table-schedule}`). Για attribute σε πίνακα βάλε τον μέσα σε div: `::: {.table-glossary}` … `:::`. Κάθε άλλος πίνακας μετατρέπεται σε λίστα/κάρτες όπως παραπάνω.

## Σύνδεσμοι
Μέσα στο κείμενο κανονικά `[κείμενο](url)`. Στο Παράρτημα Ε κάθε σύνδεσμος σε δική του γραμμή λίστας: `- [Τίτλος](url) — μία πρόταση.` (ο μετατροπέας προσθέτει QR 12 mm στα δεξιά της γραμμής για την έντυπη έκδοση).

## Παραγόμενα κεφάλαια και δείγμα
Το build.py προσθέτει στο τέλος «Συντελεστές & Βιβλιογραφία» (από `CONTRIBUTORS.md` + γραμμή άδειας) και «Ιστορικό εκδόσεων» (από `CHANGELOG.md`)· δεν γράφονται στο `content/`. `python3 tools/build.py content dist --sample` βγάζει `dist/sample.html` (εξώφυλλο, ενότητα 1.1, μάθημα 2.1, σελίδα με τις εκδοχές εικονιδίου).
