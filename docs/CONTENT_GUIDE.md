# Οδηγός περιεχομένου: πώς προσθέτεις ή αλλάζεις ένα μάθημα

Πλήρης προδιαγραφή: [`design/COMPONENT_SPEC.md`](../design/COMPONENT_SPEC.md). Ύφος και ορολογία: [`content/STYLE_BRIEF.md`](../content/STYLE_BRIEF.md).

## Βήματα
1. Βρες το αρχείο: μαθήματα Επιπέδων 1–2 στο `content/30-mathimata-epipeda-1-2.md`, Επιπέδων 3–5 στο `content/40-mathimata-epipeda-3-5.md`.
   Αντίγραψε ένα υπάρχον μάθημα ως σκελετό (ίδια σειρά ενοτήτων).
2. Γράψε με τη σύνταξη των components (πίνακας παρακάτω). Κενή γραμμή πριν και μετά από κάθε `:::`.
3. Φωτογραφίες: επεξεργασία με `python3 tools/process-photos.py <raw> assets/img/ --name <slug>` και αναφορά ως `img/<slug>.jpg`.
4. `make check`, μετά `make html` και δες το `dist/index.html`.
5. Commit: `feat(content): μάθημα X.Y – Τίτλος`.

## Σύνοψη components

| Component | Σύνταξη | Χρήση |
|---|---|---|
| Με μια ματιά | `::: {.glance level="2" dd="2" dm="2" time="40" grades="Γ'–ΣΤ'" concept="…"}` | μία ανά μάθημα, αμέσως μετά τον τίτλο |
| Υλικά και θύρες | `::: {.materials}` | λίστες υλικών/θυρών |
| Χρονογραμμή | `::: {.timeline}` | ροή μαθήματος |
| Κώδικας | `::: {.code-figure id="fig-2-1" src="img/code-2-1.png" caption="…" link="https://makecode…"}` | screenshot + QR |
| Βήματα κώδικα | `::: {.steps}` | αριθμημένη εξήγηση ①②③ |
| Τι θα πάει στραβά | `::: {.trouble}` | κάρτες σύμπτωμα / «Γιατί:» / «Κάνε:» |
| Πλαίσια | `{.tip}` `{.warn}` `{.safety}` `{.note}` | συμβουλή, προσοχή, ασφάλεια, σημείωση δασκάλου |
| Πλαϊνές σημειώσεις | `{.aside}` `{.humor}` | στο δεξί περιθώριο (≤40 / ≤30 λέξεις) |
| Κάρτα Πρόκλησης | `::: {.challenge}` | επέκταση για γρήγορες ομάδες |
| Διαφοροποίηση | `::: {.diff}` | δύο στήλες Γ'–Δ' / Ε'–ΣΤ' |
| Συζήτηση | `::: {.discuss}` | ερωτήσεις συζήτησης |
| Κατασκευή | `::: {.build url="…"}` | σημειώσεις κατασκευής |
| Καρτέλα εξαρτήματος | `::: {.component name="…" img="img/x.jpg"}` | Μέρος 1 |
| Κάρτες ρόλων | `::: {.cards cols="3"}` + `::: {.card title="…"}` | εκτυπώσιμα |
| Εικόνα | `![Λεζάντα](img/x.jpg){.fig}` | γενικές εικόνες |

Πίνακες μόνο για πραγματικά δεδομένα (κελιά ≤4 λέξεις). Επικεφαλίδες: `#` Μέρος/Μάθημα, `##` ενότητα, `###` υποενότητα.
Οι ακριβείς ιδιότητες (attributes) κάθε component βρίσκονται στο `COMPONENT_SPEC.md`· αν κάτι διαφέρει, ισχύει εκείνο.

## Τι χρειάζεται απόφαση
Αλλαγή επιπέδου μαθήματος, κλιμάκων ΔΔ/ΔΜ ή αρίθμησης: ρώτα τον συντηρητή (βλ. [AGENTS.md](../AGENTS.md)).
